    ผังการเชื่อมต่อ

    สั่งงานได้ 3 ทาง ทุกทางใช้คำสั่ง JSON ชุดเดียวกัน

    MQTT (ผ่านอินเทอร์เน็ต) WebSocket (WiFi วงเดียวกัน) USB Serial
    Topic MQTTทิศทางข้อมูล
    <prefix>/cmdผู้สั่ง → ESP32{"j":[…]} · {"ik":[x,y,z,p]} · {"grip":v} · {"home":1}
    <prefix>/stateESP32 → ผู้สั่งมุมปัจจุบัน + moving + estop (10 Hz ขณะขยับ, 1 Hz ตอนนิ่ง)
    <prefix>/statusESP32 → ผู้สั่งonline / offline (retained + Last Will)
    <prefix>/replyESP32 → ผู้สั่งerror เช่น {"err":"unreachable"}
    ทางเมื่อไหร่ใช้ทดสอบใน Wokwi
    MQTTอยู่คนละที่ / ผ่านมือถือ 4Gใช้ได้เลย (Wokwi-GUEST ออกเน็ตได้)
    WebSocketอยู่ WiFi เดียวกัน หน่วงต่ำสุดVS Code: ws://localhost:8181
    Serialdebug / ไม่มี WiFiSerial Monitor ของ Wokwi
    ความปลอดภัย: broker สาธารณะ (broker.hivemq.com) ใครรู้ topic ก็สั่งแขนได้ ใช้ทดสอบเท่านั้น งานจริงใช้ broker ส่วนตัวที่มี username/password + TLS และมีคนเฝ้า E-STOP เสมอ

    แผนผังวงจรต่อสาย

    แขนจริง: ESP32 + PCA9685 + ไฟ servo แยก · ใน Wokwi ต่อ servo ตรงที่ GPIO

    3V3 ลอจิก5–6V servo GNDSDA SCLPWME-STOP sense
    ขา ESP32ต่อไปที่หมายเหตุ
    3V3PCA9685 VCC, OLED VCCไฟลอจิกเท่านั้น ห้ามจ่าย servo
    GNDPCA9685 GND, OLED GND, PSU −ต้องต่อร่วมกันทั้งหมด
    GPIO21SDA (PCA9685 + OLED)บัส I2C เดียวกัน
    GPIO22SCL (PCA9685 + OLED)
    GPIO4E-STOP (หน้าสัมผัส NO → GND)INPUT_PULLUP · กด = สลับหยุด
    PSU +E-STOP (NC) → PCA9685 V+กดแล้วตัดไฟ servo ทันที
    CH0–CH5Servo J1–J6Wokwi: GPIO 13, 12, 14, 27, 26, 25
    ระวัง: อย่าจ่ายไฟ servo จาก USB หรือขา 5V ของบอร์ด MG996R ดึงกระแสกระชากได้ ~2.5A ต่อตัว ใช้ PSU แยก 5–6V ≥10A ใส่ C 1000µF คร่อม V+/GND ใกล้บอร์ด PCA9685
