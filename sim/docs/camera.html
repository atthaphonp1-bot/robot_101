คำแนะนำ

① เริ่มที่นี่

กล้อง USB ต่อ Pi 5 ติดสูง 50–60 ซม. ให้เห็น ~500×500 มม.

② เพิ่มทีหลัง

กล้องตัวเล็กเบาเป็นตัวที่สอง — รอให้แขนแม่นขึ้นก่อน (เช่น servo ที่อ่านมุมได้)

③ ข้ามไปก่อน

ยุ่งยากเกินประโยชน์สำหรับงานหยิบ-วางบนโต๊ะ

Calibrate กล้องด้านบน (Pi 5)

Pi OS Lite ไม่มีหน้าจอ จึงถ่ายภาพบน Pi แล้วไปคลิกจุดบน Mac จากนั้นส่งผลกลับไป Pi

  1. ติดกล้อง

    สูง 50–60 ซม. ตั้งฉากกับโต๊ะ ล็อกให้แน่น — ขยับกล้องเมื่อไหร่ต้อง calibrate ใหม่

  2. จัดแสง

    แสงสม่ำเสมอ ไม่มีเงาแข็ง หลีกแสงสะท้อนบนโต๊ะ

  3. ทำเครื่องหมาย 4 จุด

    ติดเทปกากบาทที่พิกัดหุ่น (มม. วัดจากกลางฐาน X=หน้า, Y=ซ้าย): (100, 150) · (250, 150) · (250, −150) · (100, −150) — ยิ่งห่างกันยิ่งแม่น

  4. ถ่ายภาพบน Pi

    SSH เข้า Pi แล้วรัน

    python3 -c "import cv2; c = cv2.VideoCapture(0); ok, f = c.read(); cv2.imwrite('cal.jpg', f); print(ok)"
  5. คัดลอกภาพมา Mac

    รันบน Mac

    scp <user>@robotpi.local:cal.jpg .
  6. คลิก 4 จุดบน Mac

    คลิกตามลำดับเดียวกับข้อ 3 แล้วพิมพ์ x,y ของแต่ละจุด → ได้ไฟล์ calib.json

    python3 vision/vision_pick.py --source cal.jpg --calibrate --calib calib.json
  7. ส่งผลกลับ Pi 
    scp calib.json <user>@robotpi.local:~/robot_101/vision/
  8. ตรวจความแม่น

    วางกล่องที่ตำแหน่งที่รู้ แล้วรันบน Pi — พิกัดที่พิมพ์ออกมาควรคลาดไม่เกิน 3 มม. ถ้าเกินให้ทำข้อ 4–7 ใหม่ · ต่อด้วยสั่งแขนไปลอยเหนือกล่องเพื่อดูด้วยตา

    cd ~/robot_101/vision && python3 vision_pick.py --source 0 --dry-run --no-gui
    python3 ~/robot_101/pi/arm.py --port /dev/ttyUSB0 ik X Y 80
ทำไม 3 มม.: ที่ 640px คลุม 500 มม. หนึ่งพิกเซล ≈ 0.8 มม. — คลาด 2–3 มม. ถือปกติ และพอสำหรับกล่อง 30 มม. ที่กริปเปอร์อ้าได้ 60 มม.
