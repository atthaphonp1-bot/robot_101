ผังทั้งระบบ

คำสั่งเดินทาง 5 ชั้น: ผู้ใช้ → เครือข่าย/Pi → firmware ESP32 → ไดรเวอร์ PCA9685 → servo ทั้ง 6 ตัวที่หมุนข้อต่อของแขน

ผังรวม

ข้างใน servo หนึ่งตัว

servo คือมอเตอร์ DC + เฟืองทด + ตัวต้านทานปรับค่าที่วัดมุม วงจรข้างในเทียบ “มุมที่สั่ง” กับ “มุมจริง” แล้วหมุนจนตรงกัน (closed loop)

เวลาในแต่ละช่วง

ช่วงความถี่ / เวลาหมายเหตุ
มือถือ ส่ง sliderไม่เกินทุก 120 msกดปุ่มตำแหน่งค้าง: ทุก 200 ms
Simulator ส่งท่าไม่เกินทุก 50 msDigital Twin
MQTT ในบ้าน (ผ่าน Pi)ไม่กี่ ms – สิบกว่า msผ่านเน็ต/broker สาธารณะจะช้ากว่า
Motion loop บน ESP3250 Hz (ทุก 20 ms)คุมความเร็วเป็น °/s ทุกข้อถึงพร้อมกัน
PWM จาก PCA968550 Hz, pulse 0.5–2.5 msทุกช่องพร้อมกัน ไม่กิน CPU ของ ESP32
ส่งสถานะกลับ10 Hz ขณะขยับ · 1 Hz ตอนนิ่งผ่าน MQTT / WebSocket
