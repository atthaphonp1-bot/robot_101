ลำดับที่แนะนำ

  1. ทำก่อนต่อแขนจริง — ค่าแขนที่เดียว

    robot.json + สคริปต์สร้าง robot_config.h ให้ firmware · เว็บอ่าน robot.json ตรง · ย้าย MQTT_HOST ไป secrets.h

  2. Python package เดียว

    ทำ arm_core ที่ค้างอยู่ให้เป็น host/robotarm ที่รองรับ Serial/WebSocket/MQTT แล้วให้ vision_pick.py กับ serial_test.py ใช้ตัวเดียวกัน — งานนี้เหมาะกับ orchestrator (แยกเป็นฟังก์ชันมี checks ได้)

  3. หน้า Protocol + test อัตโนมัติ

    docs/protocol.html รวมทุกคำสั่ง · GitHub Actions: build firmware + รัน Python tests ทุก push

  4. แยก Simulator เป็นโมดูล

    ย้าย JS ออกเป็นไฟล์ย่อย, ลบ diagram ที่ซ้ำแล้วลิงก์ไปหน้า docs, รวม CSS เป็นชุดเดียว

  5. ทีหลัง (ไม่รีบ)

    เปลี่ยนชื่อ sim/ → web/ (ต้องแก้ workflow + ลิงก์ทั้งหมด) · แยก main.cpp เป็นหลายไฟล์

ไม่แนะนำ: รื้อเขียนใหม่ทั้งหมด หรือเพิ่ม framework (React, build tools) — โปรเจกต์ยังเล็ก เว็บแบบไฟล์ธรรมดาเปิดได้ทุกที่และ deploy ง่าย
