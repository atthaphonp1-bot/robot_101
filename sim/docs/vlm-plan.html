สั่งแขนด้วยข้อความ (VLM บน cloud)

พิมพ์คำสั่งภาษาไทยหรืออังกฤษ → VLM ดูภาพจากกล้องแล้ววางแผน → ระบบตรวจความปลอดภัย → แขนทำงาน · หลักคิด: VLM เลือก — OpenCV วัด

ผังระบบ

สร้างแล้ว: เฟส 1 (ยังไม่ใช้ key)

ทดสอบทั้งระบบได้ใน Simulator ด้วยตัววางแผนจำลอง (mock) — พอมี API key แค่เสียบ VLM เข้าช่อง “เลือกตัววางแผน” ส่วนอื่นใช้ต่อได้ทันที · รัน python3 vlm/planner_server.py แล้วไปแท็บ “กล้อง”

ทำไมให้ VLM แค่ “เลือก”

VLM เก่งเข้าใจ

เข้าใจฉากและคำสั่งภาษาไทยได้ดี แต่บอกตำแหน่งคลาดได้หลายเซนติเมตร

OpenCV เก่งวัด

หาตำแหน่งแม่นระดับ mm ด้วย calibration ที่มีอยู่แล้ว

รวมกัน

VLM ตอบแค่เลขวัตถุและการกระทำ ไม่เคยส่งมุมหรือพิกัดเอง → ปลอดภัยและแม่น

ตัวอย่างคำสั่ง

คำสั่งรอบแรก
หยิบกล่องแดงไปวางบนแผ่นเขียวรองรับ
เรียงกล่อง แดง น้ำเงิน เหลือง จากซ้ายไปขวารองรับ
วางกล่องสีเหลืองซ้อนบนกล่องที่ใกล้สุดรองรับ
กลับท่าเริ่มต้นรองรับ
วาดรูปวงกลม / เคลื่อนที่ตามเส้นทางอิสระยังไม่รองรับ
หยิบของที่ OpenCV หาไม่เจอเฟสหลัง

รูปแบบแผนที่ VLM ตอบ

{
  "say": "จะหยิบกล่องแดง (#2) ไปวางบนแผ่นเขียว",
  "steps": [
    {"action": "pick",  "object": 2},
    {"action": "place", "target": {"pad": true}},
    {"action": "home"}
  ]
}
actionความหมาย
pickหยิบวัตถุเลข object
placeวางที่ target: pad, บนวัตถุเลข on, หรือข้างวัตถุ near + side (left/right/front/back)
homeกลับท่าเริ่มต้น
gripopen / close
stopหยุดทันที

ชั้นความปลอดภัย

  1. ตรวจรูปแบบ

    แผนต้องตรง schema · action ที่อนุญาตเท่านั้น · ไม่เกิน 10 ขั้น

  2. ตรวจวัตถุ

    เลขวัตถุต้องมีอยู่จริงในภาพล่าสุด

  3. ตรวจระยะ

    ทุกจุดต้องเอื้อมถึง (IK ผ่าน) และไม่ต่ำกว่าพื้น

  4. กดยืนยัน

    แสดงแผนเป็นภาษาคน + ภาพมีเลข แล้วให้กด “ยืนยัน” ก่อนทำ (เปิดไว้เป็นค่าเริ่มต้น)

  5. หยุดได้เสมอ

    ปุ่ม STOP ทุกหน้า + E-STOP ฮาร์ดแวร์ · ถ้าภาพหลังทำไม่ตรงแผน หยุดทันที

เฟสงาน

เฟสสิ่งที่ได้ใครทำทดสอบด้วย
1 · Simulatorกล่องพิมพ์คำสั่งใน Simulator ใช้กล้องจำลอง · planner server บน Macorchestrator: วาดเลขบนภาพ, ตรวจแผน, แปลงแผนเป็นคำสั่ง · Claude Code: เรียก VLM, server, เชื่อม UIchecks + กล่องจำลองใน sim
2 · กล้องจริงplanner บน Pi ใช้กล้อง USB + calibration เดิม สั่งแขนผ่าน arm_coreClaude Codeแขนจริง + กล่องสี
3 · มือถือช่องพิมพ์คำสั่งในแดชบอร์ด ส่งผ่าน MQTT topic <prefix>/sayorchestrator + Claude Codeมือถือจริง
4 · เสริมตรวจผลหลังทำแล้วลองใหม่ · สลับไปใช้ VLM ในเครื่องได้——
