1 · รายการอุปกรณ์

อุปกรณ์ รุ่นที่แนะนำ จำนวน หมายเหตุ
บอร์ดควบคุม ESP32 DevKit V1 (ESP32-WROOM-32) 38 ขา 1 ห้ามใช้ C3/S2/S3 หรือ WROVER (GPIO16/17 ไม่ว่าง)
บอร์ดขยายขา ESP32 terminal expansion board 38 pin 1 ไม่บังคับ แต่ช่วยให้สายไม่หลุด
ไดรเวอร์ servo PCA9685 16 ช่อง (I2C) 1 แอดเดรส 0x40
Servo MG996R (หรือชุดแขน 6DOF) 6 J1–J6
ไฟ servo Power supply 5–6V ≥ 10A 1 แยกจากไฟบอร์ด
ตัวเก็บประจุ 1000µF 16V 1 คร่อม V+/GND ที่ PCA9685
ปุ่มฉุกเฉิน E-STOP แบบมีหน้าสัมผัส NC + NO 1 NC ตัดไฟ servo · NO แจ้ง ESP32
จอ OLED 0.96" SSD1306 I2C 1 แอดเดรส 0x3C
สมอง Raspberry Pi 5 (4GB หรือ 8GB) + Active Cooler 1 ไฟ USB-C 5V 5A (27W)
การ์ด microSD 32GB ขึ้นไป 1 Raspberry Pi OS Lite 64-bit
กล้อง กล้อง USB 720p–1080p 1 ติดด้านบน สูง 50–60 ซม.
สาย USB data cable (ESP32 ↔ Pi), สาย Dupont, terminal block — สาย USB ต้องส่งข้อมูลได้ ไม่ใช่สายชาร์จอย่างเดียว

2 · ต่อสาย ESP32

ดูผังเส้นสายที่ปุ่ม วงจร ใน Simulator ประกอบ

ขา ESP32 ต่อไปที่ หมายเหตุ
3V3 PCA9685 VCC, OLED VCC ไฟลอจิกเท่านั้น ห้ามจ่าย servo
GND PCA9685 GND, OLED GND, PSU −, E-STOP (NO) GND ต้องต่อร่วมกันทั้งหมด
GPIO21 (SDA) PCA9685 SDA, OLED SDA บัส I2C เดียวกัน
GPIO22 (SCL) PCA9685 SCL, OLED SCL
GPIO4 E-STOP หน้าสัมผัส NO → GND กด = สลับหยุด/ทำต่อ
GPIO16 (RX2) / GPIO17 (TX2) Pi Pin 8 (TXD) / Pin 10 (RXD) เฉพาะทาง UART — ถ้าใช้สาย USB ไม่ต้องต่อ
USB Raspberry Pi 5 (ช่อง USB-A) ได้ทั้งไฟเลี้ยง ESP32 และ Serial — ทางที่แนะนำ

PCA9685 → Servo

ช่อง ข้อต่อ
CH0 J1 ฐานหมุน
CH1 J2 ไหล่
CH2 J3 ศอก
CH3 J4 ข้อมือก้ม-เงย
CH4 J5 ข้อมือหมุน
CH5 J6 กริปเปอร์

หัว servo: สายส้ม/เหลือง = สัญญาณ (ด้าน PWM) · แดง = V+ · น้ำตาล/ดำ = GND — เสียบให้ตรงแถวบนบอร์ด

ไฟเลี้ยง

  1. PSU + → E-STOP (NC) → PCA9685 V+

    กด E-STOP แล้วไฟ servo ตัดทันที

  2. PSU − → PCA9685 GND → ESP32 GND

    GND ร่วม ไม่งั้น servo สั่นมั่ว

  3. C 1000µF คร่อม V+/GND

    ขายาว (+) ไป V+ · กันไฟตกตอน servo กระชาก

  4. ESP32 ใช้ไฟจาก USB

    ห้ามต่อไฟ 5–6V ของ servo เข้าขา 3V3 หรือ GPIO

ก่อนเสียบไฟครั้งแรก: ตรวจขั้วไฟ PSU ด้วยมัลติมิเตอร์ · ตั้ง PSU ไม่เกิน 6V · ยังไม่ใส่ horn/แขนกับ servo จนกว่าจะถึงขั้นตั้ง Home

ทางเลือก: ไฟจากแหล่งเดียวทั้งระบบ

ใช้ PSU 12V ตัวเดียว แล้วแยกเป็น 2 สายผ่าน buck converter — ห้ามต่อ servo กับ Pi เข้า 5V เดียวกันตรง ๆ เพราะตอน servo กระชาก (ได้ถึง ~2.5A ต่อตัว) ไฟจะตกแล้ว Pi รีบูต

ส่วน แรงดัน ใช้ไฟโดยประมาณ
servo ×6 6V ใช้จริงสูงสุด ~10A (~60W)
Pi 5 + กล้อง + ESP32 5.1V ~3–5A (15–25W)
รวมที่ PSU 12V ~7A (~85W) → PSU 12.5A เผื่อพอ
อุปกรณ์ สเปก หมายเหตุ
PSU 12V ≥ 12.5A (เช่น Mean Well LRS-150-12) แบบปิดมิดชิด ต่อสายดิน
Buck servo ปรับได้ ตั้ง 6V · ≥ 20A ห้าม ใช้ตัวเล็กแบบ XL4016 (8A) ไม่พอ
Buck Pi 5.1V ≥ 5A หรือแบบ USB-C PD 27W แบบ PD ง่ายที่สุด
ฟิวส์ 15A (สาย servo) · 5A (สาย Pi) ใส่แยกแต่ละสาย
สายไฟ สาย servo/12V ≥ 16 AWG สายเล็กจะร้อนและทำให้ไฟตก
  1. ตั้งแรงดัน buck ก่อนต่ออุปกรณ์

    วัดด้วยมัลติมิเตอร์ให้ได้ 6.0V และ 5.1V ตอนยังไม่มีโหลด

  2. E-STOP อยู่ที่สาย servo เท่านั้น

    กดแล้ว servo หยุด แต่ Pi กับ ESP32 ยังทำงานต่อ

  3. Pi 5 กับ buck ที่ไม่มี PD

    Pi จะเตือนไฟไม่พอและจำกัดกระแส USB — ถ้า buck จ่าย 5A ได้จริง ให้เพิ่มบรรทัดนี้ใน /boot/firmware/config.txt

    usb_max_current_enable=1
  4. ต่อ GND ร่วม

    GND ของ PSU, buck ทั้งสอง, PCA9685, Pi และ ESP32 ต้องต่อถึงกัน

ไฟบ้าน 220V อันตราย: ใช้ PSU แบบปิดมิดชิด ต่อสายดิน ห้ามจับขั้วตอนมีไฟ — ถ้าไม่มั่นใจให้ช่างไฟช่วยต่อฝั่งไฟบ้าน

3 · ลง firmware ใน ESP32

  1. ติดตั้งเครื่องมือบน Mac

    VS Code + ส่วนขยาย PlatformIO IDE · ถ้าบอร์ดใช้ชิป USB รุ่น CH340 อาจต้องลงไดรเวอร์

  2. โหลดโค้ด

    git clone https://github.com/atthaphonp1-bot/robot_101.git
  3. สร้าง secrets.h

    คัดลอก firmware/src/secrets.example.h เป็น secrets.h แล้วใส่ WIFI_SSID/WIFI_PASS ของ router บ้าน (2.4 GHz), AP_PASS, MQTT_PREFIX และ MQTT_USER/MQTT_PASS ที่ตั้งตอนรัน setup.sh บน Pi — ไฟล์นี้ไม่ขึ้น GitHub

    cp firmware/src/secrets.example.h firmware/src/secrets.h
  4. เปิดโหมดบอร์ดจริง

    ใน firmware/src/main.cpp แก้ #define USE_PCA9685 0 เป็น 1 (0 ใช้กับ Wokwi เท่านั้น)

  5. ชี้ MQTT ไปที่ Pi

    ใน main.cpp ตั้ง MQTT_HOST เป็น IP ของ Pi (เช่น "192.168.1.50") — ESP32 ใช้ชื่อ .local ไม่ได้ · ดู IP ได้จากผลสรุปตอนท้าย setup.sh

  6. อัปโหลด

    เสียบ ESP32 เข้า Mac แล้วรันในโฟลเดอร์ firmware (หรือกดปุ่ม Upload ของ PlatformIO)

    cd robot_101/firmware && pio run -t upload
  7. ดู Serial Monitor

    ควรเห็น WiFi → IP → Ready. และ MQTT connected — ลองพิมพ์ {"home":1} ต้องได้ {"ok":1}

    pio device monitor -b 115200

4 · ตั้ง Home และประกอบแขน

สำคัญที่สุดของการประกอบ — ใส่ horn ตอน servo อยู่ท่า Home แล้ว มุมใน Simulator จะตรงกับแขนจริง

ข้อมุม servo ท่า Homeท่าทางที่ต้องจัดให้ตรง
J1 ฐานหมุน90°แขนหันไปด้านหน้า (แกน X)
J2 ไหล่90°แขนท่อนบนตั้งตรง
J3 ศอก135°แขนท่อนล่างขนานพื้นชี้ไปข้างหน้า
J4 ข้อมือก้ม-เงย135°ข้อมือก้มลง 45°
J5 ข้อมือหมุน90°นิ้วกริปเปอร์อยู่แนวเดียวกับแขน
J6 กริปเปอร์80°กริปเปอร์เปิดครึ่งทาง
  1. ต่อไฟและเปิดบอร์ด (ยังไม่ใส่ horn)

    firmware จะสั่ง servo ทุกตัวไปท่า Home ตอนบูต

  2. ใส่ horn และแขนทีละข้อ

    จัดท่าให้ตรงตามตาราง แล้วขันสกรูกลาง horn

  3. ทดสอบทีละข้อ ความเร็วต่ำ

    ส่ง {"speed":30} ก่อน แล้วขยับทีละข้อ มืออยู่ใกล้ E-STOP

  4. ปรับ offset ถ้ามุมเพี้ยน

    แก้ค่า offset/dir ในตาราง JOINTS ของ main.cpp และใน Simulator ให้เท่ากัน

ระวัง: อย่าหมุน servo ด้วยมือตอนมีไฟ · ถ้า servo ร้อนหรือส่งเสียงคราง แปลว่าดันกลไกอยู่ กด E-STOP แล้วจัด horn ใหม่

5 · ตั้งค่า Raspberry Pi 5

  1. เขียน OS

    Raspberry Pi Imager → Raspberry Pi 5 → Raspberry Pi OS Lite (64-bit) · Edit Settings: hostname robotpi, user/รหัส, WiFi บ้าน, Country TH, Enable SSH — รายละเอียดใน หน้า Pi

  2. SSH เข้า Pi และโหลดโค้ด 
    ssh <user>@robotpi.local
    sudo apt-get install -y git && git clone https://github.com/atthaphonp1-bot/robot_101.git ~/robot_101
  3. ติดตั้ง Mosquitto + OpenCV + เว็บ

    จะถามชื่อ/รหัส MQTT (ใช้ค่าเดียวกันใน secrets.h) · จด IP ที่สรุปตอนท้ายไว้

    bash ~/robot_101/pi/setup.sh
  4. (ทางเลือก) ติดตั้ง VLM planner

    สั่งแขนด้วยข้อความ · กด Enter ข้าม API key ได้

    bash ~/robot_101/pi/setup-planner.sh
  5. ต่อ ESP32 เข้า Pi ด้วยสาย USB

    เช็กว่า Pi เห็นบอร์ด (ขึ้น /dev/ttyUSB0 หรือ /dev/ttyACM0) – หลังจากเพิ่มผู้ใช้ไปยังกลุ่ม dialout ให้ logout/login ใหม่

    ls /dev/ttyUSB* /dev/ttyACM*
    sudo usermod -aG dialout $USER

6 · ทดสอบทีละชั้น

ทำตามลำดับ ผ่านข้อหนึ่งค่อยไปข้อถัดไป

  1. Serial ผ่าน USB

    ต้องขึ้น PASS ครบ 5/5

    python3 ~/robot_101/pi/serial_test.py /dev/ttyUSB0
  2. สั่งแขนจาก Pi

    แขนต้องกลับท่า Home แล้วไปลอยเหนือจุด (180, 0, 100)

    cd ~/robot_101/pi && python3 arm.py --port /dev/ttyUSB0 home
    python3 arm.py --port /dev/ttyUSB0 ik 180 0 100
  3. MQTT

    เปิดดูข้อความ — ต้องเห็น status online และ state ของแขน

    mosquitto_sub -h localhost -u <mqtt-user> -P '<mqtt-pass>' -t '#' -v
  4. Simulator บนคอม/มือถือ

    เปิด http://robotpi.local:8080/ → แท็บ เชื่อมต่อ → MQTT broker ws://robotpi.local:9001 + user/รหัส + prefix เดียวกับ firmware → ขยับ slider แขนจริงต้องขยับตาม

  5. แดชบอร์ดมือถือ

    เปิด http://robotpi.local:8080/remote.html → ⚙ ใส่ค่าเดียวกัน → ป้ายต้องขึ้น แขน online

  6. กล้อง + หยิบของ

    calibrate ตาม หน้ากล้อง แล้วลองหยิบกล่องสี (ต้องลง websocket-client ก่อนถ้าสั่งผ่าน WebSocket)

7 · แก้ปัญหา

อาการ สาเหตุที่พบบ่อย วิธีแก้
servo สั่น/กระตุก GND ไม่ร่วม หรือไฟไม่พอ ต่อ GND ร่วม · ใช้ PSU ≥ 10A · ใส่ C 1000µF
ESP32 รีสตาร์ทเอง ดึงไฟ servo จากบอร์ด แยกไฟ servo ไป PSU
servo ไม่ขยับเลย USE_PCA9685 ยังเป็น 0 หรือ E-STOP ค้าง ตั้งเป็น 1 แล้วอัปโหลดใหม่ · ดูจอ OLED ว่าขึ้น E-STOP ไหม
OLED ไม่ติด สลับ SDA/SCL SDA=GPIO21, SCL=GPIO22
MQTT ไม่ connected MQTT_HOST เป็นชื่อ .local หรือรหัสผิด ใช้ IP ของ Pi · เช็ก MQTT_USER/MQTT_PASS
Pi หา /dev/ttyUSB0 ไม่เจอ สาย USB ชาร์จอย่างเดียว เปลี่ยนสายที่ส่งข้อมูลได้
Permission denied ที่ /dev/ttyUSB0 user ไม่อยู่กลุ่ม dialout sudo usermod -aG dialout $USER แล้ว login ใหม่
IK ตอบ unreachable จุดไกล/ต่ำเกิน ลองจุดในระยะเอื้อม ~100–230 มม. จากฐาน
ความปลอดภัย: ทดสอบครั้งแรกด้วยความเร็วต่ำ มืออยู่ที่ E-STOP เสมอ · อย่าใช้ broker สาธารณะกับแขนจริง
