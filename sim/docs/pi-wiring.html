วงจร · Raspberry Pi 3 + ESP32

ต่อสาย Pi 3 กับ ESP32

Pi คุยกับ ESP32 ได้ 3 ทาง — ทางที่ง่ายและปลอดภัยที่สุดคือสาย USB เส้นเดียว

เลือกทางเชื่อม

A · สาย USB

แนะนำ

สายเส้นเดียวได้ทั้งไฟเลี้ยง ESP32 และ Serial · Pi เห็นเป็น /dev/ttyUSB0 · firmware ปัจจุบันใช้ได้ทันที

B · UART ผ่าน GPIO

ต้องแก้ firmware

ต่อ TX/RX/GND 3 เส้น ใช้ /dev/serial0 · firmware ตอนนี้อ่านแค่ Serial (USB) ต้องเพิ่ม Serial2 ที่ GPIO16/17 ก่อน

C · WiFi / MQTT

ไม่ต้องต่อสาย

ESP32 ต่อ Mosquitto บน Pi ผ่าน WiFi · ESP32 ใช้ไฟจาก adapter USB ของตัวเอง

ผังต่อสาย

ทาง B: ตารางขา UART

Pi 3 ขา ESP32 ขา หมายเหตุ
Pin 8 · GPIO14 TXD GPIO16 RX2 ไขว้ TX → RX
Pin 10 · GPIO15 RXD GPIO17 TX2 ไขว้ RX ← TX
Pin 6 · GND GND ต้องต่อเสมอ
Pin 1 · 3V3 — ห้ามต่อ 3V3 ข้ามบอร์ด

ขั้นตอน ทาง A (สาย USB)

  1. เสียบสาย USB

    จากช่อง USB-A ของ Pi ไปช่อง USB ของ ESP32 (ใช้สายที่ส่งข้อมูลได้ ไม่ใช่สายชาร์จอย่างเดียว)

  2. ตรวจว่า Pi เห็นบอร์ด

    ls /dev/ttyUSB* /dev/ttyACM*

  3. ติดตั้งตัวเปิด Serial

    sudo apt-get install -y python3-serial

  4. ลองส่งคำสั่ง

    python3 -m serial.tools.miniterm /dev/ttyUSB0 115200 แล้วพิมพ์ {"home":1} กด Enter ควรได้ {"ok":1}.

ทาง B: เปิด UART บน Pi

  1. เปิด hardware serial

    sudo raspi-config → Interface Options → Serial Port → login shell: No → hardware serial: Yes แล้ว reboot

  2. ใช้พอร์ต

    /dev/serial0 ที่ 115200 baud

ทางเลือก: Pi คุม PCA9685 เอง (ไม่ใช้ ESP32)

Pi 3 ขา PCA9685
Pin 1 · 3V3 VCC
Pin 3 · GPIO2 SDA SDA
Pin 5 · GPIO3 SCL SCL
Pin 9 · GND GND (ร่วมกับ PSU servo)

เปิด I2C ใน raspi-config แล้วใช้ไลบรารี adafruit-circuitpython-servokit · ต้องเขียน IK/การเคลื่อนที่ใหม่เป็น Python

ห้ามเด็ดขาด: จ่ายไฟ servo จาก Pi หรือ ESP32 · ต่อ 5V เข้าขา GPIO (ขา GPIO รับได้แค่ 3.3V) · ต่อ 3V3 ระหว่างสองบอร์ดที่มีไฟเลี้ยงของตัวเองอยู่แล้ว — GND ต้องต่อร่วมกันทุกบอร์ด
