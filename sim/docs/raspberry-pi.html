ระบบ · Raspberry Pi 5 + ESP32

Pi 5 เป็นสมอง ESP32 คุมมอเตอร์

ใช้ Raspberry Pi 5 ทำงานหนัก (กล้อง, broker, เว็บ, VLM planner) ส่วน ESP32 ทำงานที่ต้องตรงเวลา (servo, E-STOP) — firmware เดิมใช้ได้ทันที

ผังระบบ

Pi 5 ทำอะไรได้แค่ไหน

งานPi 5หมายเหตุ
Mosquitto MQTT brokerสบายbroker ของเราเอง ไม่ต้องใช้ broker สาธารณะ
เว็บ Simulator + แดชบอร์ดมือถือสบายเปิดจากมือถือในวง WiFi เดียวกัน
OpenCV หาวัตถุตามสีสบายภาพเต็มความละเอียดได้ลื่น ๆ
ส่งคำสั่งไป ESP32ได้MQTT (แนะนำ), WebSocket หรือสาย USB
YOLO รุ่นเล็ก / VLM บนเครื่องได้แต่ช้าใช้ได้กับรุ่น 8GB · VLM บน cloud เร็วและแม่นกว่า
คุม servo เองโดยตรงได้แต่ไม่แนะนำLinux ไม่ real-time ให้ ESP32 คุมนิ่งกว่า

สิ่งที่ต้องเตรียม

microSD 16–32GB

เขียน Raspberry Pi OS Lite (64-bit) ด้วย Raspberry Pi Imager — ตั้ง WiFi, SSH, user/รหัสผ่านไว้ตอนเขียนได้เลย ไม่ต้องต่อจอ

Adapter USB-C 5V 5A

ตัว official 27W ไฟไม่พอ Pi จะรีบูตเองตอนเปิดกล้อง · แยกจากไฟ servo แต่ GND ต่อร่วมเหมือนเดิม

กล้อง USB

ใช้กับ vision_pick.py ได้ทันที · Pi Camera (สายแพ) ใช้ได้แต่ต้องแก้โค้ดเป็น picamera2

WiFi 2.4 GHz

ESP32 รองรับแค่ 2.4 GHz (Pi 5 ใช้ได้ทั้ง 2.4/5 GHz) — ให้อยู่ router เดียวกัน

Raspberry Pi 5: ใช้ adapter USB-C 5V 5A (27W) · ใส่ Active Cooler · Pi Camera ต้องใช้สายแบบ Pi 5 (22-pin → 15-pin) ส่วนกล้อง USB ใช้ได้เหมือนเดิม · ขา GPIO/UART ใช้ตามหน้าต่อสายเดิมได้

ขั้นตอน

  1. ติดตั้ง Raspberry Pi Imager บน Mac

    ดาวน์โหลดจาก raspberrypi.com/software — เขียน OS ลง microSD ให้ในขั้นตอนเดียว

  2. เลือกบอร์ดและ OS

    Choose Device → Raspberry Pi 5 Choose OS → Raspberry Pi OS (other) → Raspberry Pi OS Lite (64-bit) · Choose Storage → microSD (32GB ขึ้นไป)

    ใช้ Lite (ไม่มีหน้าจอ) ให้ RAM/CPU เหลือไว้ให้ OpenCV และ VLM · เลือกแบบมี Desktop เฉพาะถ้าจะต่อจอใช้งาน · อย่าใช้ 32-bit

  3. ตั้งค่าก่อนเขียน (Edit Settings)

    Hostname robotpi · Username/Password ของคุณเอง · WiFi บ้าน (วงเดียวกับ ESP32) Country = TH · Locale Asia/Bangkok · แท็บ Services → Enable SSH

  4. เขียนแล้วเปิดเครื่อง

    กด Write รอเสร็จ → ใส่การ์ดใน Pi → เสียบไฟ (Pi 5 ใช้ USB-C 5V 5A) → รอ 1–2 นาที

  5. SSH เข้า Pi

    ssh <user>@robotpi.local

  6. ติดตั้ง Mosquitto + OpenCV + เว็บ

    รันครั้งเดียวบน Pi — จะถามชื่อ/รหัส MQTT แล้วติดตั้งทุกอย่าง เปิดเว็บอัตโนมัติตอนบูต และสรุปค่าที่ต้องใส่ใน firmware ตอนจบ

    sudo apt-get install -y git
git clone https://github.com/atthaphonp1-bot/robot_101.git ~/robot_101
bash ~/robot_101/pi/setup.sh

    อัปเดตทีหลัง: cd ~/robot_101 && git pull (เว็บใช้ไฟล์ใหม่ทันที)

  7. (ทางเลือก) ติดตั้ง VLM planner

    ให้สั่งแขนด้วยข้อความจากมือถือ/คอมได้ · ถาม API key (กด Enter ข้ามได้ จะใช้ mock planner) · เก็บ key ใน /etc/robot101/planner.env สิทธิ์ 600

    bash ~/robot_101/pi/setup-planner.sh
  8. เปลี่ยน broker ใน firmware

    ตั้ง MQTT_HOST ใน main.cpp เป็น IP ของ Pi (ESP32 ไม่รู้จักชื่อ .local) และใส่ MQTT_USER/MQTT_PASS ใน secrets.h แล้วอัปโหลดใหม่

  9. เปิดจากมือถือ

    http://robotpi.local:8080/remote.html → ⚙ ใส่ broker ws://robotpi.local:9001 พร้อม user/รหัส MQTT

สำคัญ: ปุ่ม E-STOP ยังต่ออยู่ที่ ESP32 และตัดไฟ servo ได้เสมอ แม้ Pi ค้างหรือรีบูต
